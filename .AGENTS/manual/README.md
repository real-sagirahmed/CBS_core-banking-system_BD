# Core Banking System (CBS) - Operational Manuals & Standard Operating Procedures (SOP)

This directory contains the authoritative operational workflows, step-by-step procedures, and standard operating runbooks mandated under **Bangladesh Bank BRPD Circular No. 12 (13 May 2024) — Guidelines on Core Banking Solution (CBS) Features and Controls (Version 2.0)**, specifically satisfying Module 12 (12.3: User Manual & Step-by-Step Guides).

---

## Training & Operational Compliance
All branch officers, operational managers, system operators, and IT administrators must be trained on these SOPs as mandated by BRPD Circular 12/2024 (Module 12.1 & 12.2).
